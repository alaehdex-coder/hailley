# HAILLEY — Nursing Portfolio

Static site (HTML + CSS + JS, GSAP and Three.js from cdnjs). No build step.

## Deploy to Vercel
**Option A — Dashboard:** push this folder to a GitHub repo → vercel.com/new → import it →
Framework Preset: **Other**, leave Build Command and Output Directory empty → Deploy.

**Option B — CLI:** `npm i -g vercel`, then run `vercel --prod` inside this folder.

## Edit
Replace the remaining `[PLACEHOLDERS]` in `index.html` (email, phone, LinkedIn, year, experience, certifications).
After deploying, set the real URL in the `og:url` / `canonical` tags.
